# Space Crawler 2

`Space Crawler 2` ist ein Mobile-Game auf Basis der Godot Engine. Das Projekt kombiniert Weltraum-Action mit Inventarverwaltung, Ausruestung, Skills und Quest-Systemen.

## Projektueberblick

- Entwickelt mit der Godot Engine 4
- Ausgelegt auf mobile Geraete
- Enthaltene Systeme: Gameplay, Inventar, Hangar, Schmiede, Skills und Quests
